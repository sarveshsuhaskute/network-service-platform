Lightweight Client-Server Network Service Platform

TCP uses length-prefixed frames on a fresh connection. UDP sends one datagram and retransmits on timeout (try it with the Packet loss tab).
Real RFC 1035 packets, authoritative for the campus.lab zone. Unknown names return NXDOMAIN. big.campus.lab (40 records) does not fit in a 512-byte UDP answer: the server sets the TC bit and the client retries over TCP.
Uploads are SHA-256 checked by the server and stored atomically. Names are whitelisted: try uploading a file whose name contains spaces or leading dots to see an error.
Each client opens its own TCP connection and sends 1 KiB echo messages. Watch active connections, threads and CPU change in the statistics panel.
The server drops each UDP datagram it receives or sends with this probability. Then use the Echo (UDP) or DNS tab with 0 retries and 2 retries and compare how often the request fails. Round-trip loss is 1-(1-p)². Tick "Adaptive timeout" in the DNS tab and run the batch again: same success rate, much lower response time.
